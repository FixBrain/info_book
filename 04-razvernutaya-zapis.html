5. Перевод в десятичную систему счисления. Развернутая запись и схема Горнера

Перед нами запись 2637: палочки связаны в пучки по семь. Сколько здесь палочек, если считать привычно, десятками? Перевести число в десятичную систему — значит найти это количество. Разберём два способа и увидим, почему они дают один ответ.

В главе 4 мы узнали, что основание N задаёт размер пучка и допустимые цифры от 0 до N − 1. Здесь основание уже известно. Разряды в данной записи нумеруем справа налево с нуля. Их веса идут в порядке 1, N, N², N³, …

Способ 1. Считаем палочки в каждом разряде

Запись 2637 говорит: в разряде № 2 лежат 2 пучка, в разряде № 1 — 6 пучков, в разряде № 0 — 3 отдельные палочки. В пучке разряда № 1 семь палочек, в пучке разряда № 2 — семь таких пучков, то есть 7 · 7 = 49 палочек. Осталось сосчитать палочки в каждом столбике и сложить.

Разобранный пример

Задача. Перевести 2637 в десятичную систему.

Цифра263
Номер разряда210
Вес7² = 497¹ = 77⁰ = 1
Вклад2 · 49 = 986 · 7 = 423 · 1 = 3

Результат. 2637 = 98 + 42 + 3 = 14310. Те же пучки нарисованы в интерактиве ниже.

Пример с буквами. F1B16 = 15 · 256 + 1 · 16 + 11 · 1 = 3840 + 16 + 11 = 386710. Каждая буква — одна цифра: F — это 15, B — это 11.

Пусть запись числа x в основании N состоит из цифр ak … a1 a0. Сложим вклады разрядов, чтобы найти значение числа.

x = ak · Nk + … + a2 · N2 + a1 · N + a0

Такую сумму называют развёрнутой записью числа. Порядок действий: пронумеровать разряды справа налево с нуля, найти веса, умножить каждую цифру на её вес, сложить.

Интерактив · веса и вклады

Задание. 1) Для 2637 найдите самый большой вклад. Почему он приходится на цифру 2, хотя в записи есть цифра 6? 2) Введите F1B и его основание 16. Сосчитайте вклады F и B и сверьте с подписями под разрядами. 3) Введите 4052 в основании 7. Найдите разряд с нулевым вкладом.

Способ 2. Постепенно развязываем пучки

В записи 2637 цифры показывают 2 пучка по 49, 6 пучков по 7 и 3 отдельные палочки. Начнём с двух больших пучков. После каждого развязывания добавим то, что лежит в следующем разряде.

На каждом шаге число палочек в одном пучке уменьшается в 7 раз, а число развязанных пучков становится в 7 раз больше. В конце все палочки лежат по одной.

2637 = (2 · 7 + 6) · 7 + 3 = 14310

Если раскрыть скобки, получится 2 · 7² + 6 · 7 + 3 — та же развёрнутая запись.

Разобранный пример · ноль в середине

Задача. Перевести 40527 в десятичную систему.

БылоРазвязываем и добавляемСтало
44 · 7 + 028
2828 · 7 + 5201
201201 · 7 + 21409

Результат. 40527 = 140910.

Что делает ноль. На первом шаге прибавили 0, и пучков не стало больше. Но умножение на 7 выполнено: 4 пучка по 343 развязаны в 28 пучков по 49. Пропускать этот шаг нельзя.

Как нельзя. Пропустить ноль: (4 · 7 + 5) · 7 + 2 = 233. Это перевод другой записи, 4527.

Проверка по весам. 4 · 343 + 0 · 49 + 5 · 7 + 2 · 1 = 1372 + 0 + 35 + 2 = 1409.

В общем виде обозначим через Hi число групп веса Ni, полученных из уже прочитанных цифр от ak до ai. Начинаем со старшей цифры и движемся к младшей.

Hk = ak
Hi = Hi+1 · N + ai, i = k − 1, …, 0
x = H0

Такой способ вычисления называют схемой Горнера. На каждом шаге умножаем предыдущий результат на N и прибавляем следующую цифру. Запись называют рекурсивной, потому что каждый новый результат вычисляется из предыдущего.

При развязывании каждая группа старшего разряда даёт N групп соседнего младшего разряда. К ним добавляем ai групп, которые уже были в этом разряде. Например, для 2637 получаем H2 = 2, H1 = 20 и H0 = 143. При i = 0 считаем отдельные палочки, поэтому H0 равно значению числа.

Интерактив · развязываем пучки

Задание. 1) Пройдите 263 при N = 7. Перед каждым нажатием назовите, сколько пучков получится после развязывания и сколько добавится. 2) Наберите 4052 при N = 7 и проследите шаг, на котором добавляется ноль. 3) Наберите 2A7 при N = 12 и найдите шаг, где прибавляется значение буквы.

Применение. Как найти неизвестное основание

До сих пор основание было известно, и мы искали значение записи. Теперь по записи и её значению найдём основание. Сначала составим уравнение, затем проверим, входят ли все цифры в алфавит найденного основания.

Пусть 23N = 1710. По схеме Горнера старшую цифру 2 умножаем на N и прибавляем младшую цифру 3.

2 · N + 3 = 17,   2 · N = 14,   N = 7.

Проверим цифры и значение. Цифра 3 допустима, когда N ≥ 4. Найденное основание 7 подходит, и 2 · 7 + 3 = 17.

Разобранный пример

В каком основании 1A0N = 26410?

Цифра A имеет значение 10. Все цифры должны быть меньше основания, поэтому N ≥ 11.

Одна группа весит N², десять групп весят по N, отдельных палочек нет. Запишем вклады.

Цифра1A = 100
ВесN²N1
ВкладN²10 · N0
N² + 10 · N = 264  ⇔  N · (N + 10) = 264

Оба множителя положительны и растут с N. При N = 11 получаем 11 · 21 = 231, а при N = 12 получаем 12 · 22 = 264. При любом большем основании произведение уже больше 264.

Проверка. В основании 12 цифра A допустима. По разрядам получаем 144 + 120 + 0 = 264. Ответ N = 12.

Когда подходящего основания нет

В равенстве 42N = 1410 цифра 4 требует N ≥ 5. Из развёрнутой записи 4 · N + 2 = 14 получаем N = 3. Это основание не подходит для цифры 4, поэтому решений нет.

Типичные ошибки

  • Разряды пронумерованы слева. Для 2637 получится 2 · 1 + 6 · 7 + 3 · 49 = 191 вместо 143. Нулевой разряд всегда самый правый.
  • Пропущен ноль. Ноль ничего не добавляет к сумме, но занимает разряд. Без него остальные цифры получают другие веса.
  • Буква прочитана неверно. A — это одна цифра со значением 10, а не «1» и не «1 и 0».
  • Цифра не меньше основания. Записи 287 не существует: цифры 8 в системе с основанием 7 нет. Прежде чем переводить, проверьте цифры.

Обобщение

  • Перевести в десятичную систему — значит сосчитать, сколько палочек во всех пучках.
  • Развёрнутая запись: x = ak·Nk + … + a1·N + a0. Каждая цифра умножается на вес своего разряда, вклады складываются.
  • По схеме Горнера начинаем со старшей цифры. Умножаем текущий результат на N, прибавляем следующую цифру и повторяем до конца записи.
  • Оба способа — одна и та же сумма, записанная по-разному, поэтому ответ совпадает.
  • Ноль шаг не отменяет: вклад равен нулю, но разряд занят, а при развязывании умножение всё равно выполняется.
Самопроверка

Задача 1. Переведите 21034 в десятичную систему.

Веса разрядов справа налево: 1, 4, 16, 64.

2 · 64 + 1 · 16 + 0 · 4 + 3 · 1 = 128 + 16 + 0 + 3 = 147.

Проверка развязыванием: 2 · 4 + 1 = 9; 9 · 4 + 0 = 36; 36 · 4 + 3 = 147.

Задача 2. Переведите 2A712 в десятичную систему.

Цифра A имеет значение 10. Веса разрядов справа налево: 1, 12, 144.

2 · 144 + 10 · 12 + 7 · 1 = 288 + 120 + 7 = 415.

Проверка развязыванием: 2 · 12 + 10 = 34; 34 · 12 + 7 = 415.

Задача 3. Переведите 31205 в десятичную систему развязыванием пучков: умножайте на 5 и прибавляйте следующую цифру.

Начинаем со старшей цифры 3.

3 · 5 + 1 = 16; 16 · 5 + 2 = 82; 82 · 5 + 0 = 410.

Последняя цифра 0, но шаг выполнить нужно: 82 пучка по 5 развязываются в 410 палочек.

Проверка по весам: 3 · 125 + 1 · 25 + 2 · 5 + 0 · 1 = 375 + 25 + 10 + 0 = 410.

Задача 4. Найдите основание, если 31N = 1610. Проверьте, допустимы ли цифры.

Из 3 · N + 1 = 16 получаем N = 5. Обе цифры меньше 5, поэтому запись допустима. Проверка даёт 3 · 5 + 1 = 16.

В этой главе из записи 2637 мы получили 143. В главе 6 начнём со 143 палочек и восстановим запись в основании 7.
