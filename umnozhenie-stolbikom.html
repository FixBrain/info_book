Ход решения целиком

В первой строке умножаем на 4. В единицах 3 × 4 = 1210, то есть две пятёрки и две единицы. Пишем 2 и переносим 2. В пятёрках 2 × 4 + 2 = 1010, то есть две группы по 25 и ноль пятёрок. Пишем 0, затем дописываем перенос 2 слева. Получаем 2025.

Во второй строке цифра 1 означает одну пятёрку. Сначала 235 × 1 = 235, затем сдвигаем запись влево на один разряд и ставим 0 справа. Получаем 2305.

Складываем строки справа налево. 2 + 0 = 2, 0 + 3 = 3, 2 + 2 = 4. Ответ 4325.
